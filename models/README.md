# 运行时模型与审计配置

本目录保存当前代码会读取的模型参数、阈值策略和审计配置，也暂时保留项目早期已经提交
的候选筛选与基线工件；后者不代表已部署能力。大型权重仍位于被 Git 忽略的 `weights/`，
不会提交到仓库。2026-08-12 起，新的实验协议、候选筛选、实拍对照结果和阶段报告统一
保存在 [`research/`](../research/README.md)，不再继续堆入本目录。

移动文件前必须先确认 `src/`、`tests/` 和命令脚本中没有运行时路径引用；运行时配置的
文件名和内容哈希属于检测契约的一部分，不能仅为整理目录而随意改名。

## P3 DDA high-confidence audit record

`ai_likelihood_dda_v1.json` is an auditable threshold record for the local
P3 card, not a model checkpoint.  The checkpoint is deliberately excluded from
Git.  It records the official checkpoint SHA-256, the threshold-selection rule,
the independent Pixart calibration cohort, and the untouched SDXL holdout
result.  Scores below the threshold are indeterminate rather than camera
evidence; JPEG recompression and resizing are known sensitivity limits.

`p2_projective_geometry_pilot_v1.json` is a compact logistic-regression and
Platt-calibration artifact.  It is committed because the local web demo must
not silently substitute an uncalibrated heuristic when it reports a number.

The artifact was trained from the official Projective Geometry
`Recent_Deepfloyd_Indoor` archive, whose extracted `test/real` and `test/gen`
folders each contain 500 images.  Entries sharing the numeric scene identifier
are kept together in the deterministic train, calibration, or held-out test
split.  The artifact records its source URL, archive SHA-256, split counts,
feature schema, and held-out metrics.

It estimates the benchmark's **AI-generated label only**.  It is not evidence
of image provenance, authenticity, editing, or the probability that an
arbitrary uploaded image was generated by AI.  Retraining is intentionally
explicit and local:

```powershell
.venv\Scripts\python scripts\build_p2_projective_geometry_registry.py `
  --dataset-root data\p2_projective_geometry_v1\extracted\Recent_Deepfloyd_Indoor `
  --source-archive data\p2_projective_geometry_v1\raw\Recent_Deepfloyd_Indoor.zip `
  --output data\p2_projective_geometry_v1\registry.json

.venv\Scripts\python scripts\train_p2_experimental_ai_confidence.py `
  --registry data\p2_projective_geometry_v1\registry.json `
  --config configs\p0.yaml `
  --output-model models\p2_projective_geometry_pilot_v1.json `
  --output-features outputs\p2_projective_geometry_pilot_v1\features.jsonl `
  --work-dir data\p2_projective_geometry_v1\p0_work
```

## P3 Nonescape Mini complementary audit record

`ai_likelihood_nonescape_mini_v1.json` records a strict, hash-pinned
Nonescape Mini complementary signal.  Its high threshold is frozen from a
separate PixArt real-photo calibration cohort.  It is not a standalone model:
on the registered four-generator test it adds only zero-new-false-positive
high-score hits to the existing Community Forensics high rule.  The audit
includes both original-decode and independently JPEG-85-reencoded held-out
results, plus the metadata-stripped complex generated-image regression.
