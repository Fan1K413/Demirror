# Demirror 研究档案

`research/` 保存不会被网页运行时读取、但支撑设计决策和复现实验所必需的材料。它与
`models/` 的边界如下：

- `models/`：当前运行时配置，以及迁移前已经提交的历史模型/候选基线工件；
- `research/records/`：预注册协议、最终审计、关键失败收据和来源中立诊断；
- `research/reports/`：面向开发者阅读的阶段总结；
- `data/`、`outputs/`、`weights/`：体积较大或可再生成的本地材料，继续由 Git 忽略。

研究记录进入仓库不表示对应候选已经部署。每个记录必须明确其数据范围、是否允许调参、
是否改变运行时策略以及不能作出的结论。被最终报告取代的中间协议、重复候选屏和完整逐图
明细不放入本目录，而是保留在本地可恢复备份中。

第二候选 LOTA 已完成固定上游源码的 CPU 预检：隔离适配器能够在不下载 ImageNet 骨干的

[LOTA CPU 预检审计](records/2026-08-19/pixel/lota_cpu_preflight_audit_v1.json)。

同一确认窗的 160 个冻结源图已逐张材料化为 JPEG-85、WebP-85、缩放恢复 PNG 和截图式
PNG 四种无元数据变体（640 个派生文件），完整清单保存在 Git 忽略的
`outputs/research/propagation_variants_openfake_confirmation_v1/`。它绑定的
[变体协议](records/2026-08-19/pixel/propagation_variant_protocol_v1.json)不读取标签作决定；
后续评分必须引用这份输出清单，不能临时更换传播配方。

五个现有像素 worker 已在其中一个固定截图式 PNG 上完成端到端兼容性探针，均返回有效分数；
该探针不读取标签、不能推导准确率，也没有修改阈值。审计见
[当前像素通道变体兼容性探针](records/2026-08-19/pixel/current_pixel_variant_compatibility_probe_audit_v1.json)。

其中 Community Forensics 已进一步完成 160 个源图、五种固定视图共 800 次的 CPU 传播审计。
批量评分与现有隔离 worker 在固定截图视图上完全等价（绝对差为 0），再按既登记阈值汇总：
原图、JPEG-85 和截图式 PNG 的高置信生成命中均为 3/80，缩放恢复 PNG 为 2/80，且该窄确认窗中
高置信实拍命中均为 0/80。WebP-85 的原始高置信命中为 7/80，但静态 WebP 按现有产品策略不具备
高置信资格，且有限复核阈值同时命中 15/80 生成图与 2/80 实拍。该结果不授权降低阈值或调整计分，
只说明此通道尚未弥补更新生成器的漏检；机器审计见
[Community 传播审计](records/2026-08-19/pixel/community_propagation_audit_v1.json)。

Nonescape Mini 也完成了相同的 800 视图审计，并在固定截图视图上与隔离 worker 完全等价。
它的高阈值生成命中较高：原图和截图式 PNG 均为 34/80，JPEG-85 与缩放恢复 PNG 均为 35/80，
WebP-85 为 37/80；但原图、JPEG-85、缩放恢复 PNG 和截图式 PNG 各有 5/80 实拍越过同一高阈值，
WebP-85 为 7/80。这一窄确认窗的实拍分布不能代表总体，却已经足以否定把旧留出集的零误报直接
外推为产品保证。因此不调高其权重、不降低阈值，后续必须先用独立实拍来源复核；机器审计见
[Nonescape 传播审计](records/2026-08-19/pixel/nonescape_propagation_audit_v1.json)。

forensic CLIP 亦完成相同审计并与隔离 worker 完全等价：高阈值在原图和截图式 PNG 均命中
15/80 生成图，JPEG-85 与缩放恢复 PNG 均为 16/80，WebP-85 为 18/80；本确认窗的 80 张实拍
在高阈值和有限复核阈值均为 0/80。它是传播后较稳定、但低召回的补充信号；其既有独立审计仍有
约 6% 的实拍高阈值命中，故这次零命中不能改变产品权重或被解释为普适保证。机器审计见
[forensic CLIP 传播审计](records/2026-08-19/pixel/forensic_clip_propagation_audit_v1.json)。

SAFE 的 v1 批处理曾把产品本应返回“不可用”的小图误作致命错误；保留 134 条无标签检查点后，
v2 改为逐图记录该状态且不放大图片。最终每种视图均有 158/160 张可运行（80 生成、78 实拍）：
原图、JPEG-85 和 WebP-85 对 80 张更新生成图均为 0/80，高阈值仅在缩放恢复 PNG 命中 2/80、
截图式 PNG 命中 1/80，所有可运行实拍均为 0/78。它确认 SAFE 不是现代生成图的通用信号；审计失败与
修正结果分别见 [SAFE v1 失败记录](records/2026-08-19/pixel/safe_propagation_audit_failure_v1.json) 和
[SAFE v2 传播审计](records/2026-08-19/pixel/safe_propagation_audit_v2.json)。

DDA 的传播审计先执行单图资源门禁。v1 虽与产品探针得到完全相同的分数，但 Windows 虚拟环境
启动器把实际解释器放在后代进程中，原采样只读到 5.3 MiB 启动器工作集，因此结果已明确作废并
保留失败记录。v2 改为每 50 ms 枚举启动器及全部后代并汇总工作集，越过 2 GiB 时终止整棵进程树；
同一冻结截图视图的峰值为 1,567,924,224 字节，两个分数均为 `0.3888949155807495`，绝对差为 0。
这授权了一次单模型常驻、逐图检查点的 800 视图 DDA 离线传播审计。完整运行中产品等价分数仍为
`0.3888949155807495`，峰值为 1,587,105,792 字节，未超过 2 GiB。冻结的 0.94 阈值下，原图、
JPEG-85、缩放恢复 PNG、截图式 PNG 的生成图命中分别为 12/80、13/80、5/80、8/80；对应可运行
实拍的命中为 1/66、2/66、0/66、0/66。WebP-85 原始命中为生成图 11/80、实拍 1/66，但静态 WebP
按现有产品规则不具备高置信资格。DDA 在该确认窗传播代理上既有低召回，也存在实拍越阈值，故不
改变阈值、网页计分或部署状态。记录见 [DDA v1 预检失败](records/2026-08-20/pixel/dda_propagation_preflight_failure_v1.json)、
[DDA v2 预检](records/2026-08-20/pixel/dda_propagation_preflight_v2.json) 与
[DDA 传播审计](records/2026-08-20/pixel/dda_propagation_audit_v1.json)。
